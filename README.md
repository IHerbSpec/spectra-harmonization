# spectra-harmonization

This is a collaborative repository for the spectral data harmonization project by IHerbSpec.

The repository organizes analysis scripts for several stages of the project, beginning with spectral data quality control for files generated from harmonization kits across participating labs. It will also host additional subdirectories for data transformation and analysis scripts as the project develops.


## Repository structure

```text
spectra-harmonization/
├── README.md                              # Repository overview and workflow notes
├── spectra-harmonization.Rproj            # RStudio project file
├── data-collection-QC/                    # Spectral file quality-control workflow
│   ├── raw_data_files/                    # Local input folder for raw spectral files
│   ├── scripts/                           # QC scripts
│   │   └── qc_spectra_files.R             # Main spectral file QC script
│   └── outputs/                           # QC outputs
│       ├── ALL_materials_QC_labeled_spectra.pdf # Multipage plots for visual QC
│       ├── qc_plots/                      # Individual QC plots in png
│       ├── files_to_delete.csv            # User-edited list of files that should not be passed to `good_files_full_filenames/`
│       ├── file_counts_by_material.csv    # For checking for 5 or more per material
│       ├── parsed_file_inventory.csv      # Parsed filename metadata
│       ├── bad_filenames.csv              # raw data files with unrecognized names
│       ├── good_files_export_log.csv      # Log of exported good files
│       └── good_files_full_filenames/     # Exported files with full filenames
└── analyses/                              # Future analyses and shared workflows
``` 

## data-collection-QC

This subdirectory contains scripts for checking spectral files and metadata before they are shared with the group.

The initial QC workflow focuses on spectral files generated by participating labs from the harmonization kits. These scripts are intended to help labs verify that files are complete, consistently named, and suitable for downstream harmonization analyses.

The QC scripts will:

- Check that spectral files follow expected filename conventions.
- Count the number of measurements generated for each material.
- Flag materials with fewer than the expected number of measurements.
- Generate visual QC plots to identify abnormal spectra.
- Produce output files that summarize file counts and flagged materials.

### Recommended setup

Open the repository in RStudio by double-clicking:

```text
spectra-harmonization.Rproj
```

This opens the repository as an R Project and sets the working directory to the repository root. The QC scripts assume that paths are relative to this root directory.

## analyses

This is an open folder where participating researchers can set up their own directories for data transformation, analysis scripts, exploratory analyses, and related outputs.

Researchers may use this folder to share workflows that support later stages of the spectral data harmonization project, including data transformation, visualization, instrument comparison, reference material analysis, and harmonized downstream analyses.

## Notes

Raw data files should generally not be committed to the repository unless they are intended to be shared through GitHub. The raw_data_files/ and outputs/ folders can be used locally or added to .gitignore as needed.
